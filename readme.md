## 📌 Sobre o Projeto

Projeto de **página pessoal/portfólio** desenvolvido como atividade prática da FIAP.  
O objetivo foi aplicar os conceitos de **HTML, CSS e JavaScript** na construção de um site moderno, responsivo e com interações visuais.

A página apresenta seções de apresentação pessoal, habilidades, formação, experiência profissional, projetos e contato — com um visual clean e identidade visual própria.

---

## 🚀 Tecnologias Utilizadas

| Tecnologia | Uso |
|---|---|
| **HTML5** | Estrutura semântica da página |
| **CSS3** | Estilização, layout responsivo e animações |
| **JavaScript** | Interatividade: cursor customizado, tabs, scroll reveal e validação de formulário |

---

## 📁 Estrutura do Projeto

```
📦 pagina-pessoal-fiap
 ┣ 📄 index.html        → Estrutura principal da página
 ┣ 🎨 style.css         → Estilos globais e responsividade
 ┣ ⚙️  script.js         → Lógicas e interações em JavaScript
 ┣ 🖼️  foto-perfil.jpg   → Foto de perfil exibida na seção Sobre
 ┗ 📖 readme.md         → Documentação do projeto
```

---

## 🧩 Funcionalidades

- ✅ **Cursor customizado** com animação de seguimento
- ✅ **Scroll reveal** — elementos aparecem com fade ao entrar na tela
- ✅ **Tabs de habilidades** — alternância entre Hard Skills, Soft Skills e Tecnologias
- ✅ **Formulário de contato** com validação em tempo real
- ✅ **Modal de confirmação** após envio do formulário
- ✅ **Layout responsivo** adaptado para mobile e desktop
- ✅ **Avatar animado** com ring rotativo e chips de características
